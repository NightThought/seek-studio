# SeekStudio 本地应用工作台

使用 `pnpm dev` 启动，打开 http://127.0.0.1:8090 ，在左上角选择功能。对话、联网搜索和 7 项应用共用三栏界面：左侧历史、中间对话、右侧配置与定时任务。

## 运行环境和数据

- Node.js 22.13+、pnpm；会议和 ASR 工作流节点需要 FFmpeg。可通过 `.env` 中的 `FFMPEG_PATH` 指定位置。
- `.env` 的 `DEEPSEEK_API_KEY` 仅由本地服务读取。手动运行也可使用浏览器设置中的 Key；定时和发布 API 必须配置 `.env`。
- 文件、配置、快照、音频和任务记录存于 `.seek-studio/`，已被 Git 忽略。密钥不会保存到任务数据库。
- 同一时间只运行一个任务。可以取消；失败后需手动重新运行。浏览器关闭不影响已开始的任务。停止服务会中断任务，重启后标为失败，不自动重新调用付费 API。
- 定时任务仅在服务和电脑运行时执行。间隔至少 15 分钟，保存后一个间隔开始首轮；服务停机错过的多个周期合并为一次执行。任务结果保存在运行记录中，无外部邮件或聊天消息投递。
- 当前后端只接受本机请求。`pnpm build` 是静态产物，不包含应用后端；7 项应用需要用 `pnpm dev` 运行。暂不提供公网多用户部署。

## 各应用的使用方式

| 应用       | 操作                                               | 输出与边界                                                                                                 |
| ---------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| OCR 工作台 | 上传文档或图片，选择文字识别/图文混排，运行        | Markdown 标题/表格/正文、JSON；选择文字自动定位左侧 PDF 页与区域，缺少坐标时只定位到页；不提供无损版式还原 |
| 文档分析   | 上传最多 20 份文件，输入问题或选择总结/对比模板    | 文件解析后调用模型分析，要求提供文件名与原文证据；只在能够确认时报告页码，不能保证模型引用绝对准确         |
| 播客生成器 | 输入主题 → 生成脚本 → 载入脚本编辑 → 合成播客      | A/B 双音色 WAV、脚本和研究来源；脚本最多 80 行，每行需以 A: 或 B: 开头；无声音克隆和专业音频编辑           |
| 会议助手   | 上传一个录音，可附参考文档，填写纪要要求           | FFmpeg 单声道转换、110 秒分段转写、片段起点时间、纪要和待办；无实时识别或可靠说话人身份标签                |
| 网页监测   | 输入链接与检测目标，可选忽略行；定时执行需保存配置 | 首次读取即可按目标回答并保存快照，同一会话后续比较变化；已保存配置修改 URL/忽略规则后需重新保存            |
| 信息订阅   | 填主题、偏好和语音选项直接运行；持续去重需保存配置 | 搜索近一天资料，按 URL 与内容去重，生成简报和可选语音；未知发布日期明确标记，语音使用简报前 3500 字        |
| 工作流     | 添加、删除、上下移动节点，设置参数，保存并运行     | 顺序节点执行记录、各步预览、最终结果与音频；支持定时和发布本地 API，暂不支持条件分支、循环或任意代码节点   |

上传文件最大 100 MiB。会议建议不超过 3 小时。OCR 不完整页会显示提示；模型输出达到上限按失败处理，避免把截断结果当成完整结果。任务失败时保留已取得的 OCR 或录音转写片段。

## 设置与对话

- 左下角「设置 → 模型与功能」配置 API Key，选择 Flash / Pro。手动请求优先使用浏览器密钥；定时任务使用 `.env`。
- 内容安全开启后请求 `safety_check.level=high` 并写入审计；关闭时使用 API 默认 `low` 检查，上游仍可能拒答。审计针对模型调用，独立 OCR、ASR、TTS、搜索/抓取端点没有该参数。日志显示完成、拒答、失败或取消，不把“未拒答”当成独立安全证明。
- 元信息开启后发送日期、星期、已配置所在地和语言。关闭后后续请求不再发送标记，包括聊天历史中的旧标记。
- 自动朗读播放当前页面中新完成的回答，原文字保留，可停止或手动重播。点击开启或发送时准备播放器；定时任务和打开历史不会自行播放。
- 应用传入同会话最近 6 轮成功回答（每条最多 12000 字）作为上下文；应用消息与结果在服务端保存，普通聊天历史在浏览器 IndexedDB。聊天 ZIP 导入导出不包含应用数据。
- 保存定时配置时同时保存模型、安全和元信息选项。修改全局设置后，需要更新配置才会影响后续定时调用。没有本地服务时，只能查看当前浏览器中的聊天审计。

## 工作流变量和节点

- `{{input}}`：工作流最上方的初始文字输入。
- `{{previous}}`：上一个节点的文字结果；第一个节点默认等于初始输入。
- 文件节点统一使用当前工作流上传的文件，不把任意文本当文件路径执行。

| 节点     | 参数/输入                                       | 结果               |
| -------- | ----------------------------------------------- | ------------------ |
| 网页搜索 | 查询词（DeepSeek 接口最多 128 个 Unicode 字符） | 搜索结果 JSON 文本 |
| 网页抓取 | 公开 HTTP/HTTPS URL                             | 页面 Markdown      |
| 模型生成 | 提示词，可插入上述变量                          | 模型文字输出       |
| OCR 识别 | 上传的文件；节点提示词不使用                    | 识别文字和逐页结果 |
| 文件分析 | 上传的文件 + 提示词                             | 文档分析结果       |
| 语音转写 | 一个上传的录音；节点提示词不使用                | 分段转写文字       |
| 语音合成 | 文字，最多 4000 字；长内容先加摘要节点          | WAV 音频及原文字   |

## 发布本地工作流 API

先保存工作流，再点击「发布 / 更换 API 令牌」。页面会显示带工作流 ID 和访问令牌的调用信息。该令牌与 DeepSeek Key 不同；可随时撤销或更换。

```sh
curl -X POST 'http://127.0.0.1:8090/studio-api/published/WORKFLOW_ID' \
  -H 'Authorization: Bearer WORKFLOW_TOKEN' \
  -H 'Content-Type: application/json' \
  --data '{"text":"需要处理的内容"}'
```

返回 `202`、任务 `id` 和 `resultUrl`。携带同一令牌 GET `resultUrl` 查看状态与结果。请求中的 `text` 可覆盖初始文字，节点定义、文件和 API Key 不能通过公开调用覆盖。

## 验证

```sh
pnpm type
pnpm lint
pnpm test
pnpm build
```

`pnpm test` 包含搜索的 8 项测试、应用后端的 14 项测试及 OCR Markdown 解析测试，共 23 项。集成测试使用模拟 DeepSeek Provider、临时 HTTP 服务及真实 FFmpeg，不产生付费调用。

可选浏览器验收：在已启动的开发服务上，用 Playwright 环境运行 `node tests/apps-ui.mjs`。也可设置 `PLAYWRIGHT_MODULE` 为其模块入口绝对路径。脚本拦截 API，验证三栏布局、7 项应用、连续追问与历史、PDF 页码/区域联动、Markdown 表格、设置持久化、审计开关、元信息移除、自动朗读、工作流发布及手机布局，截图存于 `.cache/`。

当前验收使用模拟 API 响应，真实账号可用性、上游响应延迟、OCR/转写/生成质量需要真实素材联调确认。

接口依据：[OCR](https://api-docs.deepseek.com/zh-cn/guides/ocr/)、[文件解析](https://api-docs.deepseek.com/zh-cn/guides/document_parsing/)、[ASR](https://api-docs.deepseek.com/zh-cn/guides/asr/)、[TTS](https://api-docs.deepseek.com/zh-cn/guides/tts/)、[搜索与抓取](https://api-docs.deepseek.com/zh-cn/guides/search/)。
